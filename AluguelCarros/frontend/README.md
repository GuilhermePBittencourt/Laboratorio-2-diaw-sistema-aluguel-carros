# Front-end — Sistema de Aluguel de Carros

Aplicação React 19 + Vite. A documentação completa (instalação, variáveis, arquitetura) está no
[README principal](../README.md).

```bash
npm install
cp .env.example .env   # ajuste VITE_API_URL se o back-end não estiver em localhost:8080
npm run dev            # http://localhost:5173
npm run lint
npm run build
```
